# 孟庆祥课题组主页

河海大学土木与交通学院 · 孟庆祥课题组

**线上地址：<https://kehuairan.github.io/meng-lab/>** · 仓库：<https://github.com/Kehuairan/meng-lab>

纯静态站点，无构建步骤、无外部依赖（不加载 Google Fonts / CDN），
双击 `index.html` 即可在本地预览，也可以直接上传到任何静态托管。

视觉语言参考 [empaneda.com](https://www.empaneda.com/)：黑色页头 + 荧光绿点缀 +
无衬线字体 + 细线分隔的列表式排版，首页为「肖像侧栏 + 正文」两栏结构。

## 怎么打开

三种方式，任选一种：

1. **双击 `打开网站.bat`** —— 直接用默认浏览器打开首页（不需要装任何东西）。
2. **双击 `index.html`** —— 效果相同。
3. **双击 `本地预览服务器.bat`** —— 启动本地服务并打开 `http://127.0.0.1:8000`；
   同一局域网内的手机或其他电脑可以用 `http://<这台电脑的 IP>:8000` 访问（需要 Python）。

> 这两个 `.bat` 只随本地压缩包提供。GitHub 仓库里不包含它们（中文文件名会触发
> GitHub 规则引擎的 `commit_refs_rules` 报错），克隆仓库后直接双击 `index.html` 即可。

站内所有链接和图片都是相对路径，整个文件夹拷到任何地方、或者直接上传到服务器都能用。
`孟庆祥课题组网站.zip` 是打好的整站压缩包，方便发给别人或上传。

## 五个页面的分工

| 页面 | 只负责 | 明确不放 |
| --- | --- | --- |
| 首页 | 定位、最新动态（时间线）、研究方向目录（纯标题，链接到详情）、招生入口 | 方向正文、论文列表、获奖清单 |
| 研究方向 | 6 个方向的完整说明、科研项目 | 软件清单、获奖 |

| 成果 | 获奖、软件与平台、专利与软著 | 论文、项目清单 |
| 加入我们 | 招生要求、能得到什么、申请流程、联系方式 | 团队名单、成果 |

加新内容前先确认它属于哪一类，避免同一段文字出现在两个页面。
首页的"最新动态"只写"发生了什么"，不复制各页的清单内容。

## 还需要你确认 / 补充的地方

1. **职称**：学院主页写的是「副教授」，按你的说法写成了「教授」；
   工作经历一栏只写了单位未写职称，避免两处矛盾。若需改回，搜索 `教授` 即可。
2. **负责人详情（可选）**：负责人简介、教育与工作经历、荣誉目前压缩在首页两段文字里，
   没有单独成页（避免与首页重复）。若想单列一页，新建 `about.html`，
   导航里加一项即可；`assets/css/style.css` 里的 `.person`、`.rows` 样式可以直接复用。
3. **论文 DOI**：代表性论文暂未加链接，避免出现无效跳转；有 DOI 可以逐条补
   `<span class="pub-links"><a href="https://doi.org/...">DOI</a></span>`。
4. **动态日期**：只精确到年份（官网未给具体日期）。有确切日期时把
   `<time datetime="2023">` 改成 `2023 年 5 月` 并补 `datetime="2023-05-01"`。
5. **照片**：目前用的是学院主页上的 177×235 小图，放大到 220px 会略糊，
   建议换成高清竖图（4:5，宽 1000px 左右）覆盖 `assets/img/meng-qingxiang.jpg`。
6. **示意图**：`assets/img/fig-*.svg` 是我画的极简示意图（坝基、河网、数字孪生、CAE 界面等），
   有论文插图或软件截图可以直接替换同名文件，并更新 `alt` 与 `figcaption`。

## 修改配色

打开 `assets/css/style.css`，顶部变量即可控制整体观感：

```css
:root {
  --black: #0b0b0b;       /* 页头、页脚底色 */
  --accent: #a8d800;      /* 荧光绿：页头副标题、当前导航、页脚悬停 */
  --accent-ink: #4c7300;  /* 白底上的绿色链接与条目标题（保证对比度） */
  --body-text: #555555;   /* 正文 */
  --rule: #dedede;        /* 细线 */
}
```

- 想换成学术蓝：`--accent: #9ec5ff`、`--accent-ink: #1f4b8f`。
- 想更保守：把 `--accent` 改成 `#c8c8c8`（灰线），整体就是黑白灰的极简风。
- 页头高度在 `.header-inner` 的 `min-height`，首页两栏比例在 `.layout` 的
  `grid-template-columns`。

## 部署

已部署在 GitHub Pages（`main` 分支根目录，`https://kehuairan.github.io/meng-lab/`）。
改完内容后执行：

```bash
git add -A
git commit -m "更新内容"
git push
```

或者更省事：**双击 `发布更新.bat`**，它会自动提交、推送，失败自动重试最多 8 次
（GitHub 偶尔会返回 `fatal error in commit_refs_rules`，重试即可通过），成功后提示网址。

一分钟左右自动重新构建，刷新页面即可看到。其余部署方式：

- **本地预览**：双击 `打开网站.bat`，或运行 `python -m http.server 8000`，
  访问 `http://localhost:8000`。
- **学校 / 学院服务器**：把整个文件夹（含 `assets`）上传到站点根目录即可，无需 PHP 或数据库。
- **换一个 GitHub 账号 / 仓库**：在仓库 Settings → Pages 里改分支，或重新 `git remote set-url`。

## 内容维护

- 新闻/动态：`index.html` 的 `.news` 里，一条一个 `<p>`，日期用 `<time>`。
- 论文：`publications.html` 的 `.pub-list`，复制一个 `<li class="pub">` 改内容即可。
- 项目：`research.html` 的 `.rows`，`<span class="label">` 放年份，`<p>` 放项目名。
- 成员：`people.html`，用 `.people-grid` + `.member` 两列排布。
